# Wkład w projekt

1. Utwórz gałąź roboczą.
2. Wprowadź zmianę i dodaj/zmodyfikuj testy.
3. Uruchom `ruff check apps/web-app` i `pytest -q apps/web-app/tests`.
4. Otwórz Pull Request. GitHub Actions sprawdzi lint, testy i możliwość budowania obrazu.
5. Scal zmiany dopiero po pozytywnych kontrolach.
